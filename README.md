# Breast Cancer Classification using Random Forest

## Project Description
This project uses the Breast Cancer dataset from sklearn to classify tumors as malignant or benign.

## Algorithms Used
- Random Forest Classifier
- GridSearchCV
- RandomizedSearchCV

## Techniques
- Train-Test Split (80-20)
- Cross Validation (cv=5)
- Accuracy Score
- Confusion Matrix
- Classification Report

## Result
Model comparison between baseline, Grid Search and Random Search.
